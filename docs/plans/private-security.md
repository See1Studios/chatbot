## 4. 설계

### 4.1 사적 데이터 한 곳으로 (T3·T6·T7의 바탕)

사적 세션·사적 기억·호감도(`state.json`)를 `<DATA>/private/<character>/` 아래로 모은다. 작업공간(에이전트 cwd) **밖**이라 업무 에이전트의 파일 도구 기본 범위에서 빠지고, 권한·삭제·내보내기 제외를 폴더 하나로 처리한다. 옛 위치는 읽기만 하고 이사한다(`characters.pack_file`처럼 옛 이름 호환).

### 4.2 가드

- `preview_guard`: `<DATA>/private/`와 사적 세션 폴더는 **사적 세션에서 온 요청만** 연다.
- 업무 세션 지침에 "사적 폴더 읽기 금지" + 사적 폴더를 연 도구 호출을 관찰 로그에 기록(막을 수 없는 CLI 도구에 대한 탐지).
- 개발 에이전트: `tools/session_meta.py <sid>` — 턴 수·역할·선택지 유무·오류·길이만, 본문 없음. `data/workspace/AGENTS.md`가 아니라 **엔진 `RULES.md`**에 "사적 세션 본문은 운영자 동의 후" 규칙, 훅으로 강제할 수 없는 부분은 D5.

### 4.3 화면

- **빠른 가리기**: 사적 모드에서 `Esc` 두 번(또는 단축키) → 대화 영역 흐림 + 중립 화면. 다시 누르면 복귀.
- **잠금**: 선택 사항. 사적 모드 진입·앱 복귀·N분 무입력 뒤 PIN. PIN은 해시만 저장.
- 세션 목록·탭 제목·브라우저 알림: 사적 세션은 "사적 대화"만, 본문 없음.

### 4.4 고지와 지우기

- 사적 모드 첫 진입 한 번: "대화는 선택한 모델 제공자 서버를 거칩니다" + 제공자별 설정 링크(원문 확인 후).
- "사적 대화 잊기": 캐릭터별로 사적 세션·사적 기억·호감도 삭제(확인 두 번). 백업에 남는다는 사실을 함께 알림.
