# 입력창 + 메뉴: 업무는 파일 첨부, 사적 모드는 선물

> 방향 (align/D, 2026-09-28): **핵심** — 대화 상대에게 "건네는" 행동. 업무에선 자료를, 사적 모드에선 마음을. 선물은 관계(호감도)의 개인화 레이어

> 상태: **active** (2026-09-28 초안)
> 목적: 카카오톡처럼 입력창의 + 버튼으로 건넬 것을 고른다. 업무 모드는 파일을 올려 대화의 자료로 쓰고(드래그·붙여넣기 포함), 사적 모드는 선물을 주고 캐릭터가 반응한다(호감도 상승).
> 관련: [private-mode.md](private-mode.md) §3 영구 호감도(D6–D8 미결) · [plugin-architecture.md](plugin-architecture.md)(선물 목록 = 콘텐츠 팩) · [edition-boundary.md](edition-boundary.md)(배포판 파일 범위) · [character-creation-landing.md](character-creation-landing.md)(캐릭터 취향 입력)

## 1. 운영자 요청 (2026-09-28)

"카카오톡 메신저처럼 + 버튼을 눌러서 업무 모드에서는 파일을 업로드해서 컨텍스트로 쓰거나, 사적 모드에서는 선물(기획 필요, 호감도 상승용) 같은 걸 주고 캐릭터가 반응해줬으면 좋겠어. 파일 같은 경우 드래그도 가능했으면."

## 2. 현황

- 대화창에 파일 첨부가 **없다**. 파일 선택은 SillyTavern 카드 가져오기 하나, 드래그는 팀 탭(카드)뿐.
- 이미지 생성물은 세션 `artifacts/`와 `pending_images`로 이미 다룬다(에이전트가 만든 것). 사용자가 올리는 길은 없다.
- 호감도는 [private-mode.md](private-mode.md) §3에 설계만 있고 코드가 없다. 저장 위치(D6), 시작 단계 매핑(D7), 판정 방식(D8)이 미결.

## 3. 선행 사례

| 사례 | 가져올 것 | 버릴 것 |
|---|---|---|
| 카카오톡 + 메뉴 | 한 버튼 아래 "건넬 것" 목록(앨범·파일·선물하기), 대화 흐름 안에 카드로 표시 | 결제·배송 |
| ChatGPT·Claude 첨부 | 입력창 위 첨부 칩(이름·크기·제거), 드래그·붙여넣기, 보내기 전 확인 | 계정 파일 저장소 |
| 스타듀 밸리 선물 | 캐릭터별 좋아함/싫어함, 반응이 취향에 따라 다름, 주당 횟수 제한(값어치 유지) | 아이템 획득 경제 |
| 서브컬처 게임 선물(호감도) | 선물 → 반응 대사 → 호감도 게이지 변화 연출 | 재화·뽑기 |
| Replika 선물 | 선물이 대화 소재가 되고 기억됨 | 유료 상점 |

## 4. 설계 초안

### 4.1 + 메뉴는 모드별 목록

> **변경(운영자, 2026-09-28, #338)**: + 메뉴 대신 **입력창 안의 작은 버튼** — 메시지와 같은 도메인임을 보이려고. 업무 모드 📎(첨부 뒤엔 그 파일의 아이콘, 누르면 취소), 사적 모드 🎁(선물 고르기). 입력창 위 트레이는 없고, 보낸 말풍선에 파일 카드. 보내기 버튼은 보낼 수 있을 때만 켜지고(빈 글·올리는 중이면 꺼짐) Enter 아이콘.

입력창 왼쪽 + 버튼 → 지금 모드의 항목만 보인다. 항목 목록은 데이터(모드·아이콘·라벨·동작)라서 플러그인이 더할 수 있다.

| 모드 | 항목(1차) |
|---|---|
| 업무 | 파일 첨부 |
| 사적 | 선물하기 |

### 4.2 업무: 파일 첨부

1. **넣는 길 세 가지**: + → 파일 선택, 대화 영역에 드래그 앤 드롭, 붙여넣기(스크린샷).
2. **보내기 전 칩**: 입력창 위에 첨부 칩(이름·크기·✕). 글과 함께 보낸다.
3. **저장**: 세션 폴더 `sessions/<sid>/uploads/`(사용자 데이터 안). 파일 이름 정리, 크기 상한, 민감 이름(`.env`·키 등) 거절 — 파일 미리보기 가드와 같은 규칙.
4. **에이전트에게**: 메시지에 첨부 목록(경로·종류·크기)이 붙어 에이전트가 파일 도구로 읽는다. 이미지는 이미지를 받는 프로바이더에게 이미지로. 작은 텍스트는 본문에 넣을지 D2.
5. **화면**: 보낸 말풍선에 첨부 카드(이름·크기), 누르면 파일 미리보기(FILE_LINKS_v1 모달).

### 4.3 사적: 선물

1. **선물 목록**은 콘텐츠: 이름·아이콘·분류·태그(예: 꽃·단 것·책·액세서리). 기본 목록은 템플릿, 더 많은 선물은 콘텐츠 팩(Workshop 이후).
2. **캐릭터 취향**: 카드 확장에 좋아함/싫어함 태그. 소환 마법사(ccl)의 성격 단계에서 고르거나 카드 편집에서.
3. **주기 → 반응**: 선물은 한 턴의 사용자 행동으로 보낸다(`(… 을 건넨다)`처럼 사적 모드의 행동 형식). 엔진이 취향과 맞춰 판정(아주 좋아함/좋아함/보통/싫어함)하고 `[Gift]` 맥락을 넣으면 캐릭터가 그 판정에 맞게 반응한다.
4. **호감도 변화는 엔진이 정한다**: 모델의 자기 신고(`[affection: ±N]`)가 아니라 판정표로. private-mode D8의 답 하나.
5. **값어치 유지**: 하루 횟수 제한 또는 같은 선물 반복 시 체감 감소.
6. **연출**: 말풍선 대신 선물 카드 + 반응 뒤 호감도 토스트(private-mode §4 HUD와 같은 모양).

## 7. 하지 않는 것

- 결제·유료 선물. 로컬 앱이다.
- 업로드 파일을 실행하거나 엔진 코드로 쓰는 것(배포판 경계: 사용자 데이터 안의 자료일 뿐).
- 모델이 호감도를 스스로 올리게 두는 것.
