# 사적 모드 액션 및 동적 선택지 시스템 (계획, 2026-09-24)

상태: **계획**. 실장님 요청(2026-09-24) — 행위 지시문 및 동적 예측 선택지 설계안 문서화. 착수는 실장님 승인 후.

---

## 1. 배경 및 목적

- **문제**: 일반적인 챗봇 대화는 '텍스트 발화' 중심이어서, 사적 모드(Private Mode)나 캐릭터 롤플레잉에서 스킨십·동작·현장 연출과 같은 **'행위(Action)' 상호작용**에 몰입하기 어렵다. 사용자가 행동 지문을 일일이 타이핑하는 것은 피로도가 높고, 말풍선 UI에 행동 지문이 섞여 화면이 번잡해진다.
- **해결**:
  1. 클라이언트 기반 구현(티켓 #130 `PRIVATE_INTERACTION_v1`)의 액션 선택지(`->`), 직접 행동(`/act`), 표정(`[expression:]`), 속마음(`<thought>`) 인프라와 결합.
  2. AI가 턴 종료 시 다음 상황과 감정선을 예측하여, 실장님이 취할 만한 **'행동'**과 **'대화'**를 동적 선택지(`<!--choices: ...-->`)로 능동적 제시.
  3. 실장님의 선택/입력 행동과 AI의 반응 지문이 **양방향 컨텍스트**에 명확히 기록되어 다음 턴에서도 감정선과 물리적 상태가 자연스럽게 이어지도록 보장.

---

## 2. 양방향 액션 컨텍스트 설계

대화와 행위가 자연스럽게 맞물리기 위해, 화면 표시(UI)와 내부 컨텍스트(AI 인지)를 명확히 분리한다.

| 구분 | 내부 컨텍스트 (AI가 인지하는 세션 기록) | 화면 UI (실장님이 보는 화면) |
|---|---|---|
| **실장님의 말** | `User: "오늘 힘들었어"` | 실장님 대화 말풍선 💬 |
| **실장님의 액션** | `User Action: (머리를 살살 쓰다듬는다)` 또는 `(<행동>)` | **말풍선 없음** (은은한 지문 텍스트 연출) |
| **AI의 액션(지문)** | `Assistant Action: *귀를 쫑긋거리며 얼굴을 붉힌다*` | 은은한 나레이션 지문 폰트 (이탤릭) |
| **AI의 대사** | `Assistant: "앗, 갑자기 머리는 왜 쓰다듬냥...✦"` | 캐릭터 메인 대화 말풍선 |
| **AI의 속마음** | `<thought>부끄럽지만 싫지 않다냥...</thought>` | 접이식 속마음 토글 박스(`.thought-box`) |
| **AI의 표정** | `[expression: shy]` | 메시지 상단 감정 뱃지(`.exp-badge`) |

## 3. 행위 지시문 및 동적 예측 선택지 규칙

### 3.1 시스템 프롬프트 지침 (캐릭터 지시문 규격)
사적 모드나 롤플레잉 캐릭터 카드/지침에 주입되는 표준 행동 규칙:

```markdown
### [행위 지시문 및 동적 선택지 연출 규칙]
1. [지문과 대사 분리]:
   - 행동, 신체 언어(시선, 귀/꼬리, 거리감), 감정적 반응은 반드시 이탤릭 지문(`*...*`)으로 묘사하라.
   - 캐릭터의 실제 발화는 반드시 따옴표(`"..."`) 대사로 작성하라.
2. [표정 및 속마음 연동]:
   - 응답 맨 첫 줄에 `[expression: neutral|joy|shy|serious|sorrow|tired]`를 붙여 현재 감정 상태를 표현하라.
   - 겉으로 드러내지 않는 내면 심리는 `<thought>...</thought>`로 감싸 표현하라.
3. [동적 다음 흐름 예측 선택지 (`<!--choices: ...-->`)]:
   - 응답의 마지막 줄에는 항상 현재의 신체적 거리감, 감정선, 분위기를 분석하여 실장님이 취할 법한 자연스러운 다음 흐름을 2~4개의 선택지로 예측 제시하라.
   - 선택지 구성 원칙:
     - [행동 지문]: 실장님이 취할 스킨십이나 동작 (`<!--choices: 라벨 -> (행동 지문)-->` 또는 `*행동 지문*`)
     - [대화 발화]: 감정을 이어받는 대사
     - [상황 유도]: 분위기 심화, 장난, 또는 씬 전환 제안
```

### 3.2 턴 시뮬레이션 흐름

1. **실장님**: "오늘 야근하느라 너무 지쳤어..."
2. **AI(나나)**:
   ```markdown
   [expression: tired]
   *걱정스러운 눈빛으로 다가와 조심스럽게 옷자락을 톡톡 잡아당긴다.*
   <thought>오늘따라 실장님 어깨가 너무 무거워 보인다냥... 안아드리고 싶다냥.</thought>
   "실장님, 오늘 하루 너무 무리하신 거 아니냥... 고생 많으셨다냥. 이제 모든 일은 내려놓고 푹 쉬셔야 한다냥! ✦"

   <!--choices: 쓰다듬기 -> (나나의 머리를 부드럽게 쓰다듬는다) | "나나 목소리 들으니 살 것 같네" | 안아주기 -> (조용히 나나를 끌어안는다) | "따뜻한 차 한 잔만 부탁해냥"-->
   ```
3. **실장님 액션 선택**: `안아주기` 클릭
   - UI: 실장님 말풍선 없이 은은한 지문 텍스트 연출.
   - 세션: `(조용히 나나를 끌어안는다)` 지문 주입.
4. **AI(나나) 후속 반응**:
   ```markdown
   [expression: shy]
   *갑작스럽게 품에 안기자 흠칫 놀라며 귀를 쫑긋거리더니, 이내 긴장을 풀고 등을 조심스럽게 토닥여준다.*
   <thought>심장이 쿵쾅거린다냥... 그래도 실장님이 편안해지시면 좋겠다냥.</thought>
   "...앗, 실장님... 품이 정말 따뜻하다냥. 오늘 진짜 많이 힘드셨나 보네냥... 마음껏 기대도 된다냥...✦"

   <!--choices: 깊게 안기 -> (더 깊게 품에 파고든다) | 눈 맞추기 -> (살며시 안은 팔을 풀고 눈을 맞춘다) | "고마워, 조금만 이러고 있자" | 귀 만지기 -> (나나의 귀를 살짝 만져본다)-->
   ```

## 4. 구현 및 적용 계획

- **1단계 (검증 완료 - 티켓 #130)**: 클라이언트 선택지 화살표 파싱(`->`), 표정 뱃지 렌더링, 속마음 토글 박스, `/act` 지문 전송.
- **2단계 (지침 적용)**: 사적 모드용 캐릭터 카드(`card.json`) 및 사적 지침 팩(`roles/private` 또는 캐릭터 시스템 프롬프트)에 행위 지시문 및 동적 예측 선택지 룰셋 주입.
- **3단계 — 대체됨(2026-09-24)**: [out-of-band-choices-actions.md](out-of-band-choices-actions.md)로 대체. 선택지·액션을 본문 텍스트 대신 `choices` 도구·`action` 이벤트로 전달하고, 아래 기록 보존도 그 문서 §3.3에서 다룬다. 본문 `->` 문법은 그 문서 단계 2에서 정리. (원래 내용: 세션 저장 및 이벤트 로그에서 액션 지문 이벤트가 명확한 타입(`action`)으로 저장되고, 히스토리 압축(요약) 시에도 주요 스킨십/행동 상태가 유실되지 않도록 보존 규칙 점검.)
