agy는 도구를 한 번 부를 때마다 이 4.7만을 다시 보낸다. 40번 부르는 턴은 파일을 하나도 읽지 않아도 190만이다. 여기에 캐릭터 지침 묶음과 대화 기록이 더해진다. 그래서 **턴당 호출 수**가 읽는 양만큼 중요하다.

## 2. 원인

1. **한 번 읽은 내용은 그 턴이 끝날 때까지 도구를 부를 때마다 모델에 다시 보내진다.** 그래서 40번 부르는 턴에서 1MB를 읽으면 수백만 토큰이 된다.
2. **기본 캐릭터(노노)가 `lead`와 `dev`를 함께 가져** 엔진 개발을 대화 세션에서 직접 했다. 위임하면 짧게 쓰고 버리는 작업 세션에서 일어날 일이다.
3. 큰 소스 파일을 범위 없이 통째로 읽는다(검색 후 필요한 줄만 읽지 않음).
4. 소스 파일 자체가 크다(80KB대 여럿).

T1·T2 이후 일주일치로 1절 표를 다시 뽑아 비교한다. 예산 경고와 멈춤 횟수는 `logs/events.jsonl`의 `stopped`·`system`(⚠ 이번 턴) 이벤트로 센다. 경고가 정당한 작업을 자주 끊으면 한도를 조정한다.
