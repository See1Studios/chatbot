# 사적 모드 텐션 에스컬레이션 엔진 (계획, 2026-09-25)

상태: **계획**. 실장님 요청(2026-09-25) — 사적 대화 모드에서 선택지가 평이·반복되지 않고 대화 흐름에 따라 긴장감과 감정선이 단계별로 고조(에스컬레이션)되는 엔진 레벨 설계안. 착수는 실장님 승인 후.

---

## 1. 문제 정의

1. **제자리걸음형 선택지**:
   - 턴이 5~10턴 진행되어도 선택지가 항상 1턴 수준("머리 쓰다듬기", "안아주기", "말없이 바라보기")에서 맴돔.
   - LLM 지침(프롬프트)에만 의존하면 이전 턴의 편향이나 안전 지향성 때문에 결국 상투적인 클리셰로 회귀함.
2. **텐션 단계 부재**:
   - 둘 사이의 심리적·물리적 거리감이 좁혀지는 과정(워밍업 → 의식/떠보기 → 긴장 고조 → 클라이맥스)을 추적하는 상태 엔진이 없음.
3. **선택지 간 온도차 부재**:
   - 제시되는 2~4개 선택지가 모두 비슷한 톤(다정일색)이라 실장님이 대화의 주도권을 쥐고 분위기를 이끌거나 밀당할 여지가 없음.

---

## 2. 해결 방안 (엔진 레벨 아키텍처)

### 2.1 세션 텐션 상태 머신 (Tension State Machine)
호스트 엔진(`session.py` 또는 사적 세션 컨텍스트)이 사적 대화 세션의 친밀도/텐션 단계(`tension_stage`: 1~4)를 추적한다.

| 단계 (Stage) | 상태 정의 | 분위기 및 관계성 | 선택지 기대 수위 |
|---|---|---|---|
| **Stage 1: 워밍업** | 일상 복귀, 긴장 완화 | 가벼운 안부, 피로 토로, 편안한 일상 | 가벼운 장난, 차 마시기, 기대어 쉬기 |
| **Stage 2: 의식/접근** | 거리 좁히기, 미묘한 기류 | 시선 맞춤, 짓궂게 떠보기, 미묘한 긴장감 | 옷자락 잡기, 빤히 쳐다보기, 귓속말, 놀리기 |
| **Stage 3: 텐션 고조** | 심박수 상승, 감정선 심화 | 숨소리가 닿는 거리, 손잡기, 진심 고백 | 깍지 끼기, 뺨 만지기, 얼굴 가까이 다가가기, 도발 |
| **Stage 4: 클라이맥스** | 밀착, 감정적 피크 | 꽉 끌어안음, 보내기 싫어함, 깊은 애정 | 꽉 껴안기, 목에 팔 감기, 밤새 함께 있기, 짙은 스킨십 |

- **단계 전이 규칙**:
  - 실장님이 [고조/피크] 선택지나 스킨십 액션을 선택하면 Stage 카운터 상승 (최대 4).
  - 실장님이 [밀당/화제전환]을 선택하거나 긴 쉼이 있으면 Stage 유지 또는 완만하게 완화.

### 2.2 3슬롯 텐션 구성 계약 (Slot-based Progression)
에이전트가 선택지를 뽑아낼 때, 단일 톤이 아닌 **서로 다른 텐션 레벨을 가진 3가지 슬롯**으로 구성하도록 엔진이 지침 및 검증을 강제한다:
1. **[Slot A - 밀당/장난]**: 텐션을 팽팽하게 유지하거나 살짝 튕기는 짓궂은 대사/행동
2. **[Slot B - 반 발짝 전진 (고조)]**: 현재 Stage의 분위기를 한 뼘 더 깊게 만드는 스킨십/대사
3. **[Slot C - 직진/도발 (피크)]**: 다음 Stage로 단숨에 끌어올리는 과감한 행동이나 심쿵하는 대사

### 2.3 최근 선택지 회피 및 히스토리 엔진 (Deduplication & Diversity)
- 세션 런타임에 최근 3턴 동안 제시된 선택지 라벨 및 액션 목록(`recent_choices`)을 유지.
- 턴마다 시스템 프롬프트에 히든 주입:
  ```text
  [Tension Engine Context]
  Current Stage: 3 (텐션 고조)
  Recent Choices to Avoid: ["머리 쓰다듬기", "안아주기", "고마워하기"]
  Directive: 이전 선택지를 반복하지 말고, 현재 Stage 3에 맞게 둘 사이의 거리감과 긴장감을 더 짙게 만드는 선택지 3개를 제시하라.
  ```

## 3. 구현 단계 (Tier 및 경로)

1. **1단계: 세션 텐션 추적 및 최근 선택지 버퍼 (`session.py` / `session_registry.py`)** [Tier 2]
   - 사적 모드 세션 메타데이터에 `tension_stage` 및 `recent_choices` 필드 관리.
   - 액션 선택 이벤트(`type: action`) 또는 선택지 클릭 시 Stage 갱신 로직 추가.
2. **2단계: 어댑터 컨텍스트 동적 주입 (`providers/adapter_base.py`)** [Tier 2]
   - 사적 세션 턴 생성 시 `Tension Engine Context`를 에이전트 시스템 컨텍스트에 동적으로 합성.
3. **3단계: 선택지 검증 및 백그라운드 다양성 보정** [Tier 2]
   - 파싱된 선택지가 상투적일 경우 경고 또는 필터링.
4. **4단계: 캐릭터 카드 동기화 (`data/workspace/characters/.../card.json`)** [Tier 1]
   - 사적 모드 지침에 슬롯 텐션 규격 반영.
